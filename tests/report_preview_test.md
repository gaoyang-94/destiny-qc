# 报告验收检查

## 打开报告预览页
Open {{preview_url}}.
Verify the report title is visible.

## 验证信息条五项齐全
Verify the header info bar shows all five items: 干支四柱 (four pillars with 年月日时), 公历生日, 农历生日, 五行局, and 命主/身主.

## 验证八个章节
Verify the report contains these eight sections: 性格特点、事业方向、外出与发展、感情婚姻、健康、过去几件事、未来十年与近三年、三条建议.

## 验证无脚手架词
Verify the page does NOT contain any of these words: 判词、加注、此节可验、此节可回对、生成于.
Verify the page does NOT contain 「AI 生成」.

## 验证篇幅与页脚
Verify the main text is longer than 2000 Chinese characters.
